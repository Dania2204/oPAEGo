# Wireframes de PAEGo

Wireframes de media fidelidad de **todas las vistas** de la plataforma web PAEGo
(gestión y monitoreo del PAE — Alcaldía de Pasto, Secretaría de Educación),
generados a partir de las plantillas reales de la aplicación. Listos para
insertar en el documento de grado como figuras.

- **Archivo editable en Figma:** https://www.figma.com/design/GOIIrPFTcb8IFPMx4lZ5zN
- **Formato:** PNG a 2× (alta resolución para impresión).
- **Estilo:** sistema de diseño GOV.CO (azul `#3366cc`, tipografía Work Sans),
  idéntico al de la app.
